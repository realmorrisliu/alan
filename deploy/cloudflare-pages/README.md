# alanworks.app Cloudflare Pages Inputs

This directory records the static deploy contract for `alanworks.app`.
Cloudflare Pages hosts the website root and `appcast.xml` only. Release zip
files stay on GitHub Releases and must not be copied into the Pages deploy
input.

Deploy input:

- `index.html` or the generated website root.
- `appcast.xml` generated by `scripts/generate-appcast.sh`.
- `_headers` from this directory.

After deploy, run:

```bash
scripts/check-deployed-appcast.sh https://alanworks.app/appcast.xml
```
