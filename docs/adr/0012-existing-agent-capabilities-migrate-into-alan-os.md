# Existing Agent Capabilities Migrate Into Alan OS

Existing Alan Agent capabilities should be migrated into Alan OS where they fit
the new OS model, not discarded in favor of a greenfield agent system.
Capabilities that match the new boundaries should be preserved or adapted;
capabilities that conflict with System Agent Supervisor, Agent Capability
Service, Agent Run, Context Grant, Result Contract, or Command Governance
boundaries may be reshaped or rewritten.
