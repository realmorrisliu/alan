# Proposal

## Why

The explicit unified-input delivery preserves unprefixed Agent behavior. Automatic
command interpretation requires a separate typed capability, measured qualification
and explicit activation; leaving those promises in the explicit delivery would make
its archive falsely imply completion.

## What Changes

- Consume reachable typed evaluation inside the existing Agent Machine to classify
  unprefixed input as command, Agent or ambiguous, preserving exact input text.
- Freeze labeled cases and numeric accuracy, false-execution, latency and cost budgets
  before candidate measurement. Compare deterministic and generation-only baselines.
- Run shadow classification without effects; require explicit activation after all
  gates pass, visible route presentation and a way to disable to the Agent baseline.
- Preserve explicit prefixes, request precedence, governance and bounded cancellation-aware fallback.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `alan-shell`: qualified unprefixed routing, ambiguity and evaluation fallback.
- `agent-namespace-runtime`: shadow qualification and activation gates.
- `alan-renderer-host-contract`: visible automatic command routing before effects.

## Impact

Depends on merged explicit input from `unify-agent-command-input` and delivered typed
evaluation from `add-cognitive-model-routing`. Reuses Machine, Connection, Tool Process
and evidence owners. No global router, renderer executor, provider implementation or
new authority is introduced by this handoff. Canonical specs are unchanged until delivery.
