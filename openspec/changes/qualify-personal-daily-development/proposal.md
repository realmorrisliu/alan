# Proposal

## Why

Alan can complete bounded coding tasks, but historical qualification does not establish reliable personal daily use. Measure real work and interruptions on the current product before declaring it a default coding assistant.

## What Changes

- Qualify personal macOS + Herdr work in Alan and realmorrisliu.com over two consecutive weeks and at least fifty real tasks.
- Preserve initial outcomes, classify every intervention, verify actual effects, and compare matched tasks with Codex where possible.
- Freeze task budgets and acceptance inputs after a bounded pilot; report unavailable cost honestly.
- Retain Linux regressions and add toolchains only when real tasks require them.
- Coordinate existing documentation closure and the separate autonomy, trust-posture and continuity deliveries. UI fixes require reproduced problems and their owning deltas.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `runtime-harness-contract`: Personal daily-use sample, intervention metrics, budgets and honest comparison.
- `host-mount-tool-process-sandbox-projection`: Explain unsupported shell expansion and supported search filters at the existing Bash guidance boundary, following the observed pilot refusals.

## Impact

Reuses existing native CLI, harness, rollout and AgentFS evidence. No new global runtime, automatic routing or unrelated project edits. Historical thirty-slot qualification remains unchanged.
