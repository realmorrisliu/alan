Observed UI defects are fixed in small owned changes throughout steps1–4. Do not
start another broad UI redesign. Preserve Linux regression; expand Node/TypeScript
or Python environments only for observed task needs. The website provides a real
TypeScript/pnpm task source without requiring Linux first-release parity.

Historical estimates were2–4weeks to a personal candidate and4–8weeks to a default
assistant under sustained work. They are planning estimates, not promises or
substitutes for the minimum two-week measured qualification. Full-trust delivery
must not delay or inflate the default-mode readiness result.

A supervised self-development milestone is five independently reviewed small Alan
changes, including correction of review findings. Report it separately; it does
not prove reliable delegation or unattended general bootstrap. Root fallback cannot
qualify a failed child. No self-development runs start solely from this plan.

Background/always-on lifetime, scheduled work, multi-device entry, broad proactive
memory and full mixed-Machine expansion remain out of scope. Preserve existing
Process/Memory Store ownership; no new global Project or Conversation executor.
